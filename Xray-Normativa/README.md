# Xray-Normativa — línea base funcional aprobada

**Documento normativo protegido por consentimiento previo del propietario.**

Esta carpeta contiene una copia íntegra de la documentación maestra que originalmente se conservaba en la VPS como `Xray_Manager_Documentacion_Final_2026-10-31`. Sus archivos Markdown y YAML constituyen la línea base funcional aprobada del proyecto Xray Core Manager.

## Regla de integridad y modificación

- **Está prohibido modificar, corregir, reformatear, renombrar, mover, eliminar o sustituir cualquier archivo de esta carpeta sin consentimiento previo, explícito y específico del propietario.**
- La autorización para desarrollar una etapa, corregir código, actualizar documentación técnica o publicar cambios en GitHub **no** autoriza a modificar esta documentación normativa.
- Si se detecta un error, ambigüedad, obsolescencia o mejora posible, se debe conservar intacto el original, documentar el hallazgo y presentar una propuesta separada. Esperar autorización expresa antes de tocar los archivos normativos.
- Una modificación autorizada debe identificar los archivos y secciones afectados, el motivo, el impacto y la aprobación recibida; además, debe quedar registrada en `HISTORY.md`.
- No se debe reescribir retroactivamente la línea base para ocultar divergencias entre requisitos e implementación. Las decisiones complementarias se registran por separado.

## Contraste obligatorio por etapa

Antes de diseñar o implementar cualquier etapa, subetapa, módulo, protocolo, modalidad o funcionalidad, se debe leer la documentación aplicable de esta carpeta y contrastarla punto por punto con el estado real del repositorio, la VPS, el código, las pruebas y la documentación técnica. El informe de conformidad, ausencias, divergencias y pendientes se presenta antes de editar o implementar. Si la documentación no está disponible o existe una contradicción relevante, se detiene el trabajo y se consulta al propietario.
