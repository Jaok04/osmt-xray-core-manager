# Code of Conduct

## Our commitment

Open Server Management Tools (OSMT) is intended to be a welcoming, practical learning environment for people with different levels of experience.

We are committed to respectful participation, especially for beginners asking questions while learning Linux, software deployment and server operations.

## Expected behavior

- Be respectful, patient and constructive.
- Explain technical criticism with evidence and alternatives.
- Welcome questions and documentation improvements.
- Give feedback about the work, not personal characteristics.
- Respect different experience levels and communication styles.
- Acknowledge contributions and correct mistakes transparently.

## Unacceptable behavior

- Harassment, intimidation, insults or personal attacks.
- Discriminatory or sexualized language or imagery.
- Publishing private information without permission.
- Deliberate disruption, threats or sustained bad-faith conduct.
- Encouraging unsafe actions against systems without authorization.

## Maintainer responsibilities

Project maintainers may edit, reject or remove contributions and may restrict participation when necessary to protect the community.

## Reporting

Report conduct concerns privately to the repository owner through the contact method on the GitHub profile. Include relevant context and links. Do not publish private information in a public issue.

This code of conduct applies to project spaces, issues, pull requests, reviews and other community interactions associated with OSMT.
